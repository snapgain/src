
# SnapGain

SnapGain is a modern platform for offer comparison, partner integration, secure authentication, and online payments.

## Features
- Real-time comparison of products and services
- Authentication with Supabase and Google
- Payment integration (Stripe, Apple Pay)
- API for multiple partners (OpenBanking, Plaid, Amex, Mastercard, Visa, Rakuten, Shop.com, RetailMeNot, JamDoughnuts)
- Responsive and modern interface with React, Vite, and Tailwind

## Project Structure
- `src/` - Main source code (components, pages, contexts, utilities)
- `plugins/visual-editor/` - Plugins for visual editing and development mode
- `public/` - Public and static files
- `tools/` - Auxiliary scripts

## How to run the project
1. Install dependencies:
   ```powershell
   npm install
   ```
2. Start the development server:
   ```powershell
   npm run dev
   ```
